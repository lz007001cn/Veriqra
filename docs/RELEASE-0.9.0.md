# Veriqra v0.9.0

状态（2026-10-28）：最终展示验收通过。ECS 尚未启动，本版暂未部署。

- 串联需求、AI 候选用例、计划、执行、缺陷处理和复测关闭；保存后提供对应的下一步入口。
- AI 显示生成依据，候选可编辑、选择、舍弃并保存为草稿；JUnit 导入保留预览、映射、历史和来源查询。
- 首页接入 ECharts 6.0.0，展示所选运行进度、失败／阻塞用例、项目未关闭缺陷和有效需求覆盖，异常项可打开具体执行记录。
- 用户维护接入 Bootstrap Table 1.24.2，支持服务端全量搜索、角色／状态筛选、排序和分页。组件均随 WAR 本地打包，页面与图表配色统一调整。
- 基础成员和负责人迁入项目设置；裁撤小组任务、任务转交、积分排行及冗余后台页面，后台保留用户维护。
- 执行表单在快照与历史加载完成后才允许填写；“查看导入来源”只对确认有 JUnit 导入记录的运行显示。

沿用现有 35 张表，无 DDL 升级；线上业务数据和本地已有记录保留。数据库与 AI 配置继续放在应用包外，已有 v0.3 实例使用原配置升级。

发布版本号为 `0.9.0`，WAR 为 `veriqra-0.9.0.war`。[候选 v0.9.0-rc.1](https://github.com/lz007001cn/Veriqra/releases/tag/v0.9.0-rc.1) 与 [正式 v0.9.0](https://github.com/lz007001cn/Veriqra/releases/tag/v0.9.0) 使用同一提交、同一 WAR；提交、构建时间与文件摘要见发布附件 `build-info.json` 和 `SHA256SUMS.txt`。

验证：前端 308 项通过；Java 179 项通过、1 项跳过；独立 MySQL 94 项全部通过。本地独立项目 `V09FINAL28` 完成真实 AI 生成 5 条候选、人工校订与保存、就绪及覆盖确认、计划创建运行、PASS／FAIL／BLOCKED／SKIPPED 记录、JUnit 三结果导入、新运行 PASS 复测与缺陷关闭。首轮失败、修复结果和关闭回执均保留；所有 ZZZSwitch 执行记录明确为教学模拟。

演示顺序见 [ZZZSwitch 演示脚本](demo/ZZZSWITCH-DEMO.md)，运行配置见 [AI 与 JUnit 说明](V0.3.md)，后续上线结果记入 [ECS 部署记录](ECS-DEPLOYMENT.md)。
