# 管理后台系统信息

管理员可从“管理后台 → 系统信息”（`admin/system.html`）查看当前服务的版本、运行环境和配置概况。页面为信息查看入口；AI 模型选择仍在“AI 设置”中维护。

首屏集中展示应用版本、构建提交与构建时间、应用及数据库状态、运行时长。运行环境、应用参数和 AI 配置分区默认折叠，可按需展开；刷新或切换语言保留当前标签页的展开状态。

- 版本与构建信息来自当前 WAR 的构建元数据，不通过版本字符串推断是否为最新部署。提交号表示构建基准，未提交的本地改动不会改变该值。
- Java、Tomcat、操作系统、处理器与 JVM 堆内存数据来自当前服务进程。已用内存、已分配内存与最大堆上限分别展示。
- 会话超时、应用路径与数据库连接池参数反映当前运行配置。数据库参数及来源在启动时记录，修改外部文件后需要重启才能生效。
- AI 模型与配置状态来自当前模型设置，可通过“AI 设置”入口进行维护。读取本页面不会向 Google 发起查询或内容生成请求。
- 应用显示时区与 JVM 默认时区分别展示，避免把同为 UTC+8 的不同时间设置混为一项。

接口为 `GET /api/admin/system`，沿用管理员校验，不新增数据表或配置写入。凭据仅展示配置状态，不返回密码、密钥、数据库连接串、凭据路径或完整环境变量。查询失败或未知字段显示实际状态或 `—`。
