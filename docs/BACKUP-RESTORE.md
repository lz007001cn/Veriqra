# 数据备份与恢复

部署前保留当前 WAR 和 MySQL 备份。使用外部客户端配置提供连接参数，执行 `mysqldump --single-transaction --routines --triggers --set-gtid-purged=OFF`，记录文件校验值。备份与凭据保存在仓库外。

需要检查备份时，恢复到一个新的本地数据库，并使用对应 WAR 启动检查表、项目及主要页面。恢复目标不要指向现有业务库。

v0.3 升级到当前 v0.9 开发版沿用 35 表，不需要重建或覆盖数据。退役功能的历史表保留。新版页面继续读取现有项目、需求、用例、计划、运行和缺陷。

实际部署步骤及已部署版本见 [ECS 部署记录](ECS-DEPLOYMENT.md)。
