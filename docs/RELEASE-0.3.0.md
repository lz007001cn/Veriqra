# Veriqra v0.3.0

- 接入 Vertex AI，根据需求生成 3～5 条候选用例，支持编辑、选择、舍弃及整批保存为草稿。
- JUnit 导入提供历史、详情、来源导航和响应丢失后的请求结果恢复。
- 项目创建表单和成功提示随导航收起，创建入口仅保留在仪表盘。
- 提供基于 ZZZSwitch 历史版本的完整演示文案与合成 JUnit 报告。

使用现有 35 张表，无新增数据库迁移。AI 配置参考 `config/ai.example.properties`，凭据保留在应用包外。

验证覆盖 Java 基础测试、相关 MySQL 集成、前端回归、真实模型调用及本地浏览器操作。部分历史 R1 与旧迁移套件需要各自的专用测试环境。
